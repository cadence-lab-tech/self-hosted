# Cadence Lab — self-hosted

Cadence Lab runs a configurable software development cycle where AI agents
work as specialists (analyst, developer, reviewer, QA) and every step is
gated by artifacts, cross-checks and human approval.

This repository will hold everything a company needs to run Cadence Lab on
its own machine: a Docker Compose stack, install, upgrade, backup and restore
scripts, and an administrator guide.

**Status: beta.** The package is being prepared; container images will be
published later. Until then there is nothing to install from here yet.
